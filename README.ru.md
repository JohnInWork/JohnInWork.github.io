Одна статическая страница: HTML, CSS и немного JavaScript — без сборки и зависимостей. Навигация двумерная: вверх-вниз переключаются разделы (Intro, Games, Sites), вбок листаются работы внутри раздела. Работы — квадратные плитки, акцентный цвет каждой взят из неё самой. На телефоне сворачивается в обычную колонку, при системном запросе на меньше движения анимации отключаются.
