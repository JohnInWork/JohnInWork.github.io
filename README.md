A single static page: HTML, CSS and a bit of JavaScript — no build step, no dependencies. Navigation is two-dimensional: scrolling up and down moves between sections (Intro, Games, Sites), sideways moves through the works inside a section. Works are square tiles; each accent colour is taken from the work itself. Collapses to a normal column on phones and drops the motion when the system asks for reduced motion.
